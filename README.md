## 🎯 Cómo trabajo

- **Código claro antes que código ingenioso:** prefiero la solución sencilla y mantenible.
- **Estructura y convenciones:** separación de responsabilidades y commits con sentido.
- **Entornos reproducibles:** Docker y `docker compose` para bases de datos y servicios.
- **Siempre aprendiendo:** cada proyecto nuevo incluye algo que no sabía hacer al empezar.
